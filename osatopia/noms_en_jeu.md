# Noms en jeu

Le jeu est **en anglais**, comme pokeemerald-expansion. Les fiches restent en
français (avec le nom anglais entre parenthèses pour les attaques et talents
vanilla) ; ce tableau donne le nom affiché en jeu pour tout ce qui est custom.

**Exceptions gardées telles quelles** : les noms propres inventés par Dofus
(Tofu, Blop, Biblop, cawotte, Hakam, noms d'espèces…) et les talents liés à
un Dofus (Turquoise, Pourpre, Ébène, Vulbis…).

Les constantes du code (`MOVE_DECHIRURE`, `ABILITY_RAGE_FAUVE`…) gardent le
nom français de conception.
